# Front-end work

- Before writing or changing any page, component or style, invoke the `frontend-design` skill.
- Before using a front-end library, framework or tool, check its current docs with Context7. Use the latest APIs it shows, not ones from memory.
- Follow `docs/BRAND.md` for the look.
- Every front-end app meets `docs/WEB_STANDARDS.md`.
- Nothing on a page reads or looks AI-made: follow `docs/AI_SMELL.md`.
- Build only from the app's approved `docs/design/DIRECTION.md`, made through `docs/DESIGN_PROCESS.md`. If there is none, run the `design-direction` skill first.
