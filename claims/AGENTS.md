# AGENTS.md

The claims app: the UnderCover Agent decides travel insurance claims the way a handler does, and the team sees the queue and each decision. Nothing is built yet; its folders, such as `research/`, `agent/`, `api/` and `web/`, are added as its plans need them.

## Start here

Before you plan, build or change anything in this app, or answer questions about it, read each of these in full:

1. `claims/docs/SPEC.md`: what the business needs from this app
2. `docs/DISCOVERY.md`: the problem it solves, the baseline and the success criteria
3. `docs/TECH_STACK.md`: the tech choices
4. `docs/CODE_STANDARDS.md`: how to write the code
5. `docs/PROCESS.md`: how to plan, build and check the work
6. `docs/BRAND.md`: the look
7. `docs/WEB_STANDARDS.md`: the standards every front-end app meets
8. `docs/DESIGN_PROCESS.md`: how every front end is designed
9. `claims/docs/STATUS.md`: what's built so far and how to run it
10. `claims/docs/plans/`: the plans, with the one in progress listed in `claims/docs/STATUS.md`
