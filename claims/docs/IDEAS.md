# Ideas

From the use-case workshop in `docs/discovery/06_use_cases.md`. None is in the spec yet.

- **Chasing missing documents.** Ask customers for the documents a referred claim needs, and chase them. Writing to customers completes the lethal trifecta, so it needs a fresh security review first. See `docs/discovery/08_autonomy_and_risk.md`.
- **A copilot for handlers.** Questions about a claim, the wording or the manual, answered in the dashboard. Revisit once the agent is live and handlers can say what they would ask it.
- **Patterns for Special Investigations.** Spot patterns across claims. Waits until fraud losses are measured, so there is a baseline.
